Это исходный код программы-сниффера (анализатора) протокола Modbus RTU для Windows, написанный на C++ с использованием Win32 API. Программа представляет собой графическое приложение, которое подключается к COM-порту и отображает обмен данными между master- и slave-устройствами по протоколу Modbus RTU.

Основное назначение — перехват и визуализация Modbus RTU трафика. Она подключается к COM-порту, слушает его и разбирает пакеты по полям.

Разбор протокола
Для запроса (master) программа разбирает 8 байт:

адрес устройства, команда, номер регистра, количество регистров, CRC

Для ответа (slave) — адрес, команда, количество байт, значение регистра, CRC

Для каждого пакета отображаются три представления:

ASCII (сырые символы)

DEC (десятичные числа)

HEX (шестнадцатеричные 0xNN)
